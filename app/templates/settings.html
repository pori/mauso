Settings

Point mauso at any OpenAI-compatible endpoint. Base URL should be given exactly as you'd pass it to the OpenAI SDK's base_url -- i.e. it normally already ends in /v1 (e.g. http://litellm:4000/v1 for this host's own LiteLLM, or https://api.openai.com/v1). mauso appends /chat/completions and /embeddings itself.

The API key, if any, is encrypted at rest on this server (not with your conversation passphrase -- see README.md) so the backend can call your endpoint on your behalf. It is never sent to the browser.
